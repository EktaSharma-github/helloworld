# Hello World

A minimal introductory repository used to demonstrate the basic GitHub/project workflow.

## Purpose

The project provides a small starting point for practicing repository creation, source-file changes, commits, and pushing code to GitHub.

## Getting started

Clone the repository and inspect the source file that contains the example program. Run it with the toolchain appropriate to the file type.

## Learning goals

- Understand the structure of a Git repository
- Make a small source-code change
- Commit and push changes
- Use GitHub as a remote project repository

This repository is intentionally small; its value is as a clean starting example rather than a production application.
