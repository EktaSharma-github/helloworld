I’m interested in the part after the demo.

My projects tend to start with a messy problem: too much information, too many steps, or a workflow that is difficult to repeat. I use AI, data, and software engineering to turn that problem into a system that can actually be used.

That means thinking about orchestration, grounding, data flow, failure modes, interfaces, and documentation — not only getting a model to produce an impressive answer once.
